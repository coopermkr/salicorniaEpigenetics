This repository contains code for the upcoming manuscript "Conflicting signals of multi-omic nitrogen adaptation between greenhouse and field trials in a non-model salt marsh plant." In this project we use RNA-seq data from a controlled greenhouse experiment to identify genes that are differentially expressed when plants are stressed by common nitrogen pollutants. We then take this information to the field to examine genetic and methylation divergence between wild marsh populations. We end by investigating the gene ontology of the most differentially expressed and divergent genes.

The code in this repository may be helpful to those wishing to analyze methylation data from Nanopore sequencing. Our custom R scripts are written to be parallelized on an HPCC array, which we have found greatly reduces runtime and overall memory requirements.
